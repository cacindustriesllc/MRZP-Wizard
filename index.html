How it works

Run O00005 (DWO ACCURACY TEST) at several angle combos, read the X/Y/Z error (G154 P53 = probed − target) for each, and type them in below. This fits the correction δ that makes the error vanish, using error = (I − R)·δ. The suggested MRZP is current setting + δ. Check the residuals before you touch a setting — big residuals mean bad data or wrong axis map, not a real center.
Ground rules for good numbers
• Set G54 to the ball center at HOME (all rotaries 0) before running the test — same as an MRZP cal.
• Give it variety: for X/Y you need at least two different rotary (C) angles; to pin Z you need a tilt (A/B) angle in the mix. Pure C-only data can't find δZ.
• 5–8 rows spread across the travel beats 3 clustered ones. More rows = averages out probe noise.
• Units don't matter to the math — just keep every number in the same unit as Setting 9 (inch or mm).
